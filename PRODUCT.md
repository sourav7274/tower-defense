# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Desktop players looking for a strategic-casual tower-defense campaign. They play with mouse and keyboard in a focused 15–25 minute session and need to make rapid, legible placement and upgrade decisions.

## Product Purpose

Arcane Bastion is a complete, self-contained browser tower-defense game. Players protect a magical citadel through fifty escalating waves by placing, upgrading, and selling defensive towers.

## Positioning

The game makes its performance work inspectable: the same build includes a reproducible Performance Lab that contrasts a clearly-labelled naive reference with the production simulation and renderer under the same seeded load.

## Operating Context

The campaign runs locally in a modern desktop browser, with no account, network services, or saved profile. Players control time, select towers, and inspect tactical state without leaving the battlefield.

## Capabilities and Constraints

- Fifty-wave campaign, health, gold, score, tower placement, upgrades, selling, pause, restart, and speed controls.
- At least three distinct tower types and four distinct enemy types.
- Desktop mouse and keyboard are first-class; tablet layout is usable but not a primary input target.
- The stress scenario must support 5,000 enemies, 100 towers, and 1,000 projectiles with stable simulation memory and responsive controls.
- No external runtime services or externally hosted art are required.

## Brand Commitments

Arcane kingdom: rune-carved defenses, elemental magic, a fortified citadel, and readable tactical drama rather than grim militarism or generic neon sci-fi.

## Evidence on Hand

The app itself, its repeatable benchmark results, and the local Performance Lab are the product demonstrations. There are no supplied logos, customer claims, commercial claims, or external assets.

## Product Principles

- Tactical state is always readable before decoration.
- Every visual effect must clarify combat, control, or consequence.
- Performance claims are demonstrated in the product, not merely stated.
- A complete first run should be satisfying without persistence or external systems.

## Accessibility & Inclusion

Provide keyboard-operable game controls, visible focus states, readable contrast, reduced-motion behavior for UI flourishes, and text alternatives for non-text controls.
