# Runtime asset credits

This project uses a curated subset of **Tiny Swords** by Pixel Frog.

- Source: https://pixelfrog-assets.itch.io/tiny-swords
- Runtime subset: terrain, elevation, water, bridge, trees, knight buildings, goblin/knight units, fire, and explosions.
- The original source pack, ZIP archive, and Aseprite files remain excluded from the production bundle.
- Use follows the license terms supplied by the asset author. Raw asset files are not redistributed separately.
